# neo4j-dataflow-visualizer

This repository contains planning artifacts for a Neo4j-based application that visualizes dependencies between Informatica IDMC CDI pipelines.

- `SPEC.md`: 日本語の仕様書。目的、機能要件、Neo4j データモデル、API/UI 要件、ロードマップなどを記載。

Additional implementation assets will be added in future iterations.

## Mermaid データモデル

仕様書の Neo4j データモデルを mermaid で可視化した図は [DATA_MODEL.md](./DATA_MODEL.md) を参照してください。
